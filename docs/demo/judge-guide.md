# 심사위원 체험 안내 (요약)

1. 배포 주소 첫 화면(`/`)이 체험 진입 화면이에요. 새 세션을 만들 수 있어요.
2. **AI 분석 보기** `/ops` — 테스트 영상에서 사람·테이블을 검출하는 과정. "이 브라우저에서 직접 분석"을 누르면 여러분의 기기에서 AI 모델이 실제로 돌아갑니다.
3. **분할 화면 체험** — 키오스크에서 두 브랜드 메뉴를 주문하면 번호표가 2장 나옵니다. 하나만 직원 화면에서 완료하면 그 주문만 모니터와 휴대폰에 바뀝니다.
4. **학생 앱** `/app` — 정문에서 본 키오스크 6대의 예상 대기, 자리 혼잡, 브랜드별 준비시간.

데이터 구분: 영상 AI·예측 계산·QR·주문 연동은 실제로 동작하고, 학교 CCTV·키오스크·결제·주문 이력은 모의입니다. 메뉴·가격은 공개 자료의 참고값입니다.

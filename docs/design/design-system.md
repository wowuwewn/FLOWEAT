# 디자인 시스템 v2 — "Commons Floor"

v1(Entrance View 도식 + 카드 목록)을 대체한다. 근거와 레퍼런스 분석: [reference-review-v2.md](reference-review-v2.md). 전후 비교: [compare/](compare/).

## 원칙
1. **지도가 곧 앱**: 학생 홈은 지도 + 지도 위로 올라오는 시트. 데스크톱은 왼쪽 상시 지도 + 오른쪽 패널.
2. **확인된 것만 또렷하게**: 정문, 좌우 키오스크 3대, 이용자 방향(바깥에서 통로 쪽을 봄), 이용자 뒤로 서는 줄, v1보다 넓은 중앙 통로만 그린다. 그 너머는 "아직 확인 전인 공간" 안개. 거리·크기는 개념 배치.
3. **학생 시점 ≠ 카메라 시점**: 학생 지도는 정문에서 안쪽을 보는 시점. AI 카메라 위치는 운영 화면에서만, "가정"으로 표시.
4. **숫자와 상태 문법**: 범위("3–5분"), tabular 숫자, 색 + 글자. 관측(실선/진한 막대) / 예측(빗금·점선) / 판단 어려움(빗금).
5. **실제 이벤트만 상태를 바꾼다**: 주문 패스는 접수 → 완료 두 단계. 예상시간은 참고로만 쓰고, 완료 상태는 만들지 않는다.
6. **절제된 강조**: 강조색은 간판 청색 하나. 혼잡 색은 줄 바닥 띠와 점에만 쓴다.

## 지도 엔진 (`src/components/map/`)
- `geometry.ts`: 미터 단위 개념 좌표, 원근 카메라(기본 68°), 상자 면 가시성 판정, 화면 맞춤.
- `CommonsMap.tsx`: 바닥·통로·격자 → 안개 → 줄 바닥 띠(혼잡 색) → 키오스크(흰 상자, 화면은 이용자 쪽 어두운 면) → 사람(주문 중 청색, 대기 슬레이트) → 예상시간 알약 라벨.
- 상호작용: 탭 선택(목록과 동기화), 더블탭·+/− 버튼·Ctrl+휠·핀치 확대, 확대 중 드래그 이동. 확대하지 않았을 때는 세로 스와이프가 페이지 스크롤을 막지 않음(UX 테스트로 검증).
- 시각 비교: 90°(평면), 62°, 45°, 64°, 70°를 같은 데이터로 렌더링해 비교. 45°는 줄끼리 라벨이 겹치고, 90°는 공간감이 없어 68°로 결정.

|---|---|
| `/` 체험 진입 | 한 줄 소개 + 실제 지도 미리보기 + 5개 화면 바로가기 + 체험 순서 + 세션·상황 + 실제/모의/미확인 구분 |
| `/app` 홈 | 지도(52vh, 고정) + 시트: 헤드라인 예상시간, 상황 한 줄, [주문 줄·자리·수령] 탭, 키오스크 목록(펼치면 근거), 시간대 차트 |
| 자리 탭 | 4인 테이블/1인석 빈자리 수, 구역별 막대(사용/판단 어려움/비어 보임), 시간대 차트 |
| 수령 탭 | 브랜드별 준비시간, 카운터 위치 미확인 명시, 내 주문 브랜드 강조 |

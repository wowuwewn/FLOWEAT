# 디자인 시스템 — "Entrance View"

## 원칙
1. **정문에서 본 그대로**: 지도는 북쪽이 아니라 정문에 서서 안을 보는 시점. 확인된 관계만 그림.
2. **숫자가 주인공**: 핵심 수치는 tabular, 굵게, 범위로(“3–5분”). 설명은 한 줄.
3. **관측 / 예측 / 모름**: 실선 = 관측, 점선+옅은 띠 = 예측, 빗금 = 판단 어려움. 지도·차트·막대에서 같은 문법.
4. **Order Island**: 진행 중 주문은 상단에 고정. 완료되면 초록 카드가 펼쳐지고 소리·진동. 진행률은 만들지 않음(접수 → 완료 2단계).
5. **신뢰는 조용히**: 출처·검증 상태는 필요한 화면에 한 문장으로. 반복 배지 금지.
6. **재질은 지도에만**: 원목(oak)·벽돌(brick)은 Entrance View와 자리 막대에만. UI 틀은 흰색과 타일 회색, 단국 청색.

## 화면별 형태
- 학생: 480px 단일 열, 하단 탭 3개(지금·메뉴·내 주문), 상세는 바텀시트.
- 키오스크: 세로형, 왼쪽 브랜드 레일 + 메뉴 타일, 메뉴마다 "준비 n–m분" 한 줄, 하단 장바구니, 글자 크게.
- 직원: 태블릿, 큰 번호와 완료 버튼, 10초 되돌리기.
- 모니터: 남색 배경, 브랜드별 열, 새 번호 노란색 반짝임(3회), 시뮬레이션 손님 번호는 흐리게.
- 운영: 데스크톱, 영상 위 오버레이(구역 점선, 테이블 실선, 역할별 박스 색).

## 모션
- 의도적으로 하나: 줄의 점이 인원 변화에 따라 부드럽게 이동. 나머지는 사용자 행동에 대한 반응(시트, 완료 카드). `prefers-reduced-motion`이면 모두 끔.

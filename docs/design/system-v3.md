## 형태
- 모서리: 타일 12, 카드 16, 시트 22. 카드는 정보가 묶여 있을 때만(주문권, 공간 격자). 목록은 선 없이 여백으로.
- 상자(칩)는 데이터에만: 지도 위 예상 대기, 주문 번호.
- 그림자는 지도 위에 떠 있는 것(칩, 확대 버튼, 상단 칩)에만.

## 화면별 결정
- 지도: 2D 평면, 정문이 아래. 층별 시점(대기열=키오스크, 좌석·수령=홀 전체), 모르는 곳은 그리지 않고 흐리게.
- 대기열: 정문 기준 2×3 격자. 좌석: 테이블 하나 = 칸 하나(빈 자리 녹색). 수령: 매장 + 짧은 위치 + 모니터 번호.
- 키오스크: 실제 흐름 유지, 음식 사진 대신 선 아이콘(그릇 종류). 직접 그린 음식 일러스트와 비교해 선 아이콘이 더 일관돼 보여 채택.
- 문구: 상태를 먼저(“1–3분”, “빈 4인 테이블 22개”, “영수증 지참”). 조사 과정·한계는 `/data`.

# PRD v2.0과 최신 현장 근거의 차이

기준: `docs/product/PRD_v2.0.md`(2026-11-24) vs `docs/evidence/floweat-handoff-2026-11-24/`. PRD 요구사항은 삭제하지 않고, 표시 방식만 최신 근거에 맞춥니다.

| # | PRD / 디자인 레퍼런스 | 최신 현장팩 | 개발 처리 |
|---|---|---|---|
| 1 | 확인 브랜드: 비비고고, 가오슝 (나머지는 후보) | 운영사 죽전 목록 7개: 바비든든·포포420·값찌개·경성카츠·비비고고·광뚝·폭풍분식. 가오슝은 사용자 관찰뿐, 51장국밥·도쿄야는 방문기·가격 목록 | 10개 모두 사용, 브랜드 상세에 확인 경로를 한 문장으로 표시(`verification`) |
| 2 | 중식대장, Kitchen 101, 1847 SALWICH COFFEE 언급 | 2026 근거 없음(2025 자료) | 운영 데이터에서 제외 |
| 3 | 비비고고 "8코트" 등 코트 번호 | 2025 코트표는 9행으로 10개 매장과 불일치 | 코트 번호 전부 `null`, UI 비표시 |
| 4 | 공용 모니터 약 2–3대 | 2025 사진 한 프레임에 2대(하한), 현재 수·위치 미확인 | 모니터 수·위치를 데이터에 넣지 않음 |
| 5 | 키오스크 6대 | 2026-04 무장애 키오스크 추가, 6대 포함 여부 미확인 | 6대 유지, `accessible: null` |
| 6 | 주문번호 공통 체계와 브랜드별 번호표 설명이 함께 있음 | 모니터 사진은 매장별 번호 리스트 | 브랜드별 표시번호 + 서버 고유 ID + 조회 토큰 분리 |
| 7 | 메뉴 탐색이 핵심 | 학교 포털·앱에 실시간 식단 존재 | 메뉴 복제 대신 준비시간 예측을 강조, 오늘 식단은 학교 앱 안내 |
| 8 | 메뉴 가격 119항목 | 제3자 목록, 게시일·현재 판매 미확인, 도쿄야 "음료" 0원 표기 | 0원은 "가격 미표기", 모든 가격에 참고값 안내 |
| 9 | 디자인 레퍼런스 사진(P01–P07) | 일부 원문 403, 이 개발 환경 네트워크에서도 학교·운영사 사이트 접근 불가 | 사진을 제품에 쓰지 않고 자체 도형으로 구성 |

## 2. 실내 안내도 및 공간 업데이트
### 안내도 자체에서 확인되는 것 (IMG_0747)
- 출입구 하단 중앙 주변 좌우에 각각 `키오스크` 영역. 출입구 양쪽 구역이 명시된 안내도라는 기존에 없던 근거다.
- 도면 상단 노란 영역 표기 순서: 바비든든 → 포포420 → 중식대장 → 폭풍분식 → 값찌개 → 경성카츠.
- 오른쪽 청색 영역에 뽀까뽀까(표기 판독), 51장국밥, 그 뒤 일부 간판/텍스트가 사진 오른쪽에서 잘림. 정확한 마지막 전체 열은 미확인.
- 좌측 카페1847 구역과 별도의 `키오스크` 표기, 화장실·계단·무대 표기. 카페 키오스크 표기는 식사 키오스크 6대에 합산하지 않는다. 카페 주문이 같은 시스템과 연동된다는 근거도 없다.
- 중앙 녹색 도형은 표기상 용도 불명. 좌석·식재·기둥 등으로 단정하지 않는다.
- 안내도는 최신 운영 목록과 불일치한다. 중식대장·뽀까뽀까를 현재 매장으로 복구하지 말고, 현재 키오스크 탭·호출 모니터·실제 간판을 우선한다. 중식대장과 가오슝의 정확한 교체 관계는 확인되지 않았다.
- 사진에 안내도 오른쪽 일부와 하단 좌측 일부가 누락/가림. 실제 축척 도면이 아니므로 픽셀→m 환산 금지. 현재 코드의 9.2m 등은 표현용 가정값이며 실측값이 아니다.
### 기존 사용자 확인 사항(그대로 유지)
정문 기준 좌우 각 3대, 왼쪽 이용자는 오른쪽, 오른쪽 이용자는 왼쪽을 바라보며 주문한다. 대기열은 각 주문자 뒤쪽으로 형성된다. 중앙 이동 공간은 넓다. 정확한 각도·거리·위치·CCTV 배치는 미확인.
### 실제 사진으로 새로 확인한 배식 관계
- IMG_0749: 값찌개와 경성카츠가 연속된 카운터에 인접.
- IMG_0750: 가오슝과 폭풍분식이 연속된 카운터에 인접. 그 바깥의 먼 매장은 단정하지 않는다.
- 안내도의 노란 매장 영역과 연속 카운터 사진을 함께 활용해 지도 상 **참고 매장 구역 및 인접 관계**를 표현할 수 있다. 정확한 수령 좌표, 브랜드 전체 순서 및 정문 방향에 대한 실제 지도가 완성됐다고 주장하지 않는다.

## 3. 현행 브랜드 및 키오스크/호출 구조
키오스크 영상의 탭과 호출 모니터 사진을 교차 확인한 10개 브랜드:
바비든든, 비비고고, 포포420, 가오슝, 폭풍분식, 값찌개, 경성카츠, 도쿄야, 51장국밥, 광뚝.
`field_verified_2026_11_25` 또는 현재 코드의 `field_observed`에 날짜와 근거를 추가. 현재 운영 시스템에 등록된 것이 확인된 것이지 항상 전 메뉴 판매 중이라는 뜻은 아니다.
- 키오스크 화면 탭 순서(영상): 첫 줄 바비든든 / 비비고고 / 포포420 / 가오슝 / 폭풍분식; 둘째 줄 값찌개 / 경성카츠 / 도쿄야 / 51장국밥 / 광뚝. 탭 정렬은 물리적 수령대 순서가 아니다.
- 호출 모니터 A(사진): 왼쪽 첫 열은 잘려 판독 불가, 뒤의 네 열은 포포420 / 가오슝 / 폭풍분식 / 값찌개. 첫 열은 남은 브랜드 바비든든일 가능성이 높으나 직접 확인되지 않았다.
- 호출 모니터 B(사진): 경성카츠 / 도쿄야 / 51장국밥 / 광뚝 / 비비고고. 열마다 번호가 세로로 나열된다.
- 기존 단일 10브랜드 화면은 통합 체험 편의상 유지 가능. 독립 호출 화면에서는 실제 밝은 청색 표, 브랜드별 번호 열, 2개 화면 구조를 참고. 번호색의 정확한 업무 의미는 미확인이고 새 완료 번호 강조는 자체 시연 규칙으로 구분한다.
- IMG_0747의 안내문: 메뉴 픽업시 주문영수증 지참 또는 제출 요청, 영수증 미발행시 벨을 눌러 달라는 문구. 간이영수증 선택 시 매장명만 출력되고 메뉴명은 출력되지 않는다는 안내. FLOWEAT QR은 실제로 인쇄되는 기존 번호표의 신규 제안이며 종이 영수증 없이 수령 가능하다고 보장하지 않는다.
- 영상에 노출된 결제용 QR과 FLOWEAT 주문 추적 QR은 별개. 실제 결제수단 연동·번호표 포맷·직원 완료 이벤트는 여전히 모의 연동이다.

## 6. 여전히 필요한 자료 (추가 촬영 최우선 순서)
1. 안내도 전체를 정면에서 찍은 사진(사람과 결제정보 없이, 오른쪽 영역 포함). 지금 확보한 안내도를 보완하는 가장 가치 높은 사진.
2. 정문 기준 좌우 키오스크 3대 전체와 중앙 통로가 한 장씩 보이는 넓은 사진. 실제 거리/각도 단정 금지.
3. 동의받은 팀원들의 고정 카메라 연출 영상: 실제로 줄 서기, 주문 교대, 통행자, 가방만 있는 자리, 모든 물건을 치우고 완전히 빈 테이블. 기존 12초 키오스크 조작 영상은 이 평가에 사용할 수 없다.

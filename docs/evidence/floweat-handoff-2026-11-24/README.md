## 파일
- `FLOWEAT_research.md`: 출처, 사진 원본 링크, 영상 챕터·검증 한계, 2025/2026 증거 차이, 공식 문의 경로.
- `FLOWEAT_evidence.json`: 10개 브랜드 이름 후보·119개 참고 메뉴, 공식·사용자·제3자 근거, 시점과 미확인 항목.
- `FLOWEAT_menu_reference.csv`: 메뉴·가격 참고 목록. 엑셀에서 열 수 있음. 최신 메뉴 확정표가 아님.
- `FLOWEAT_space.svg`, `FLOWEAT_space.png`: 편집 가능한 SVG와 미리보기. 축척·실측 없이 확인된 입구 관계만 표현.
- `FIELD_CHECK.md`: 한 번에 미확인 부분만 채울 현장 표.

# 생성형 AI 활용 기록

공모전 제출 시 “생성형 AI를 어디에, 어떻게 썼는지”를 숨기지 않기 위한 기록입니다. 날짜별 상세는 [dev-log/](../dev-log/).

## 쓴 도구
| 도구 | 용도 | 비용 |
|---|---|---|
| Claude Code (Anthropic, 클라우드 세션) | 설계 초안, 코드 작성, 테스트 작성·실행, 배포 검수, 문서 초안 | 팀 구독 범위, 서비스 런타임 호출 없음 |
| 별도 Claude Code 세션 | **독립 검수**(커밋 5c7a281 기준) — 다른 세션이 코드를 처음부터 읽고 재현·검증 | 위와 같음 |

서비스 안에서 생성형 AI를 실시간으로 호출하지 않습니다(결정 D-006, 비용 0원 원칙). 영상 분석은 생성형 AI가 아니라 공개 검출 모델(YOLOX, Apache-2.0)입니다.

## 생성형 AI가 만든 산출물과 사람 검수 필요 여부
| 산출물 | 위치 | 상태 |
|---|---|---|
| 메뉴 119행 조리 유형 분류 | `data/menu-classification.json` | **사람 검수 필요** |
| 공개 영상 육안 라벨(카운터·테이블) | `data/labels/counter.json`, `tables.json` | **사람 검수 필요** |
| 합성 테스트 영상과 정답 | `scripts/vision/make_bank_video.py` | 생성 프로그램이 정답을 기록(라벨링 아님). 사람 이미지는 CC BY 4.0 영상 |
| 시뮬레이션 가정값 | `src/core/data/calibration.json` | 가정값. 현장 측정으로 교체 대상 |
| 화면 문구, 문서 초안 | `src/`, `docs/` | 팀 검토 후 제출 |

## 사람(팀)이 정한 것 → [team-roles.md](team-roles.md)
기획 방향, 현장 확인(키오스크 방향·줄 위치), 디자인 승인, 비용·외부 서비스 제한, 배포 설정, 독립 검수 지시는 팀이 결정했습니다. AI가 낸 결론 중 검수에서 틀린 것으로 드러난 것(예: “비스듬한 카메라가 모든 지표에서 우수”, v2 줄 집계가 단순 집계보다 낫다는 암묵적 가정)은 지우지 않고 정정 기록을 남겼습니다(`docs/ai/vision.md`, `docs/product/decisions.md` D-013 → D-018).

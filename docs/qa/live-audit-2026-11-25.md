# 실제 배포 검수 (2026-11-25)

대상: Vercel 미리보기 (PR 브랜치, 커밋 2c46ee2), 로그인 없이 접속. Playwright(Chromium)로 직접 조작·캡처. 같은 커밋을 로컬 `next start`(공용 저장소 없음)로 띄워 픽셀 비교 → 24개 화면 중 23개 동일, 1개는 일시적 차이(재측정 시 동일). 배포 전용 오류 없음.

## 통과
- 14개 경로 로그인 없이 200, `/demo` → `/`, 없는 주소 404.
- 키오스크 두 브랜드 주문 → 번호표 1.2초 → QR 실제 디코딩(배포 주소) → 같은 브라우저에서 연결 → 직원 완료 → 다른 탭 학생 화면 386ms 반영, 모니터 실제 번호만 강조, 새로고침 후 유지. 다른 기기에서 같은 QR은 한 기기 모드 안내.
- 브라우저 직접 추론: 모델 3.4MB·런타임 6.2MB(압축), 첫 결과 2.5–2.8초, WASM 4스레드 44–50ms/프레임.
- 첫 응답 0.1–0.4초, 로드 0.8–1.7초.

# 테스트 계획

## 자동 테스트
| 종류 | 명령 | 범위 |
|---|---|---|
| 단위 | `npm test` | 브랜드별 주문 분리, 멱등 완료, 표시번호, 입력 검증·세션 격리, 만료, 예측 시간 경과 후에도 ready 금지, 되돌리기 10초, SHA-256 일치 |
| E2E | `npm run build && npm run e2e` | 4개 독립 브라우저(키오스크·휴대폰·직원·모니터) 기기 간 루프, QR 실제 디코딩, 재스캔 중복 없음, 한 브랜드만 완료, 지연 측정(<2.5초), API 멱등·권한, 한 기기 모드, 잘못된 QR |
| 모델 | `npx tsx scripts/check-models.ts` | 대기·준비 백테스트, 단기 예측 비교 |
| 영상 | `npm run vision:eval` | 모델별 라벨 비교 |
